# Contributing

Thanks for your interest in this repository.

This is a personal profile repository maintained by **@Galileo927**. Public visibility does not imply that external users may directly modify the repository.

## Contribution workflow

- Do not push directly to the default branch unless you are an explicitly authorized collaborator.
- External contributions should be submitted through a fork and pull request.
- Keep pull requests focused and limited to one clear purpose.
- Explain why the change is needed and what it changes.
- Do not include unrelated formatting rewrites, generated bulk edits, personal-data changes, or dependency/configuration changes without prior discussion.
- The maintainer may close unsolicited or out-of-scope pull requests without merging them.

## Review and merge policy

- All changes to protected branches should go through pull requests.
- Repository-wide ownership belongs to **@Galileo927** as defined in `.github/CODEOWNERS`.
- A pull request should not be merged until the repository owner has reviewed and approved it.
- Passing automated checks does not guarantee that a pull request will be merged.
- Final merge decisions remain with the repository owner.

## Security and personal information

Do not add, modify, or expose personal contact information, credentials, tokens, private keys, or other sensitive data in a pull request.

By submitting a pull request, you agree that your contribution may be reviewed, modified, rejected, or merged at the maintainer's discretion and subject to the repository's license and applicable GitHub terms.
